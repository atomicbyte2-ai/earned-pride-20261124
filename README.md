## The line

> After three winters of patching the same roof, my grandfather stood back in the rain and watched the bucket stay empty.

Three winters of patching, one dry bucket — the pride is in the rain, not in a speech.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no dependencies.
